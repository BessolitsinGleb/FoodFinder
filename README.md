# FoodFinder

Сервис для закупщиков в food-сегменте: собираете корзину (сырьё, ингредиенты, готовая продукция,
упаковка), он находит поставщиков — сначала рядом с вами, — проверяет документы и отзывы, сравнивает
по прозрачной формуле и готовит письма-запросы КП. Есть помощник — Морковка, с ней можно обсудить
подборку или поправить корзину в чате.

- `backend/` — FastAPI, PostgreSQL, Redis, DeepSeek V4 через OpenRouter, поиск Tavily. Подробно — [backend/README.md](backend/README.md).
- `frontend/` — HTML, CSS и JS без сборки. Подробно — [frontend/README.md](frontend/README.md).

## Что реализовано

**Аккаунт**
- Регистрация с подтверждением почты 6-значным кодом. Код живёт 10 минут, после 5 неверных
  попыток сгорает, повторно — не чаще раза в минуту. Без верного кода войти нельзя.
- Вход по email и паролю (JWT), профиль: имя, город, регион. Удаление аккаунта со всеми данными.
- Каждый видит только свои закупки, предложения и письма.

**Корзина**
- Популярные категории на выбор (сортируются по тому, что чаще заказывают) и вариант «Другое».
- Позиции с требованиями и объёмом: г, кг, т, мл, л, шт, тыс шт.
- Вопрос «Доставка в ваш город?» перед поиском: можно подтвердить или указать другой адрес.
- Сколько поставщиков показывать на каждую позицию — от 1 до 5.

**Поиск поставщиков**
- Ищет в интернете от ближнего к дальнему: город → регион → федеральный округ → Россия.
- По каждому найденному: цена, минимальная партия, срок и условия доставки, регионы работы,
  контакты, сайт, документы, ИНН, отзывы, источники.
- Рейтинг безопасности 1–5 по формуле (документы, ИНН, отзывы, упоминания, возраст компании).
  Метки «Безопасный» и «Популярный». Ликвидированные компании отбрасываются.
- Итоговая оценка 0–100 с разбивкой: видно, почему поставщик выше или ниже.
- Примерная стоимость по каждой позиции и сумма заказа — если цена известна.
- Прогресс поиска виден на странице, страницу можно закрыть — поиск продолжится.

**Письма**
- Выбираете поставщиков — получаете письмо-запрос КП на каждого (если у поставщика выбрано
  несколько позиций — одно письмо на все). Копирование и скачивание в .txt.
- Поля с личными данными ([ФИО], [Телефон] и т.п.) остаются пустыми: ваши данные в нейросеть
  не передаются. Шаблоны писем — обычные .txt-файлы.

**Помощник Морковка**
- Чат с агентом: отвечает про поставщиков и документы, сравнивает подборку, ищет в интернете.
- Может поправить корзину по просьбе — но только в открытом заказе.
- Помнит последние 20 сообщений, история стирается сама через час тишины.

**Надёжность и безопасность**
- Не больше 3 запросов в секунду на пользователя; один активный поиск на пользователя.
- Защита от prompt injection: тексты со страниц и из корзины передаются модели как данные,
  права агента ограничены в коде.
- Пока модель думает, сервер не держит подключение к БД, а хеширование паролей не блокирует
  остальных — много пользователей могут работать одновременно.
- Светлая и тёмная тема, вёрстка под телефоны.

## Быстрый старт

```bash
python -m venv venv && source venv/bin/activate
pip install -r backend/requirements-dev.txt
cp .env.example .env              # заполнить ключи, БД и SMTP

createdb food_suppliers
redis-server &

cd backend && alembic upgrade head && uvicorn main:app --reload    # API на :8000
cd frontend && python -m http.server 5173                         # сайт на :5173
```

Открыть http://localhost:5173.

## Docker

```bash
docker compose up --build        # сайт — http://localhost:8080, API — http://localhost:8000/docs
docker compose down              # остановить (данные БД остаются в томе pgdata)
```

Postgres и Redis поднимаются в контейнерах, ключи берутся из `.env`.

## Деплой на VPS

Прод — `docker-compose.prod.yml`: Caddy (HTTPS с автоматическим сертификатом) отдаёт `/api/*`
бэкенду, остальное — фронту; Postgres и Redis наружу не открыты.

```bash
# один раз на чистом Ubuntu (от root)
git clone https://github.com/BessolitsinGleb/FoodFinder.git /opt/foodfinder
sh /opt/foodfinder/deploy/setup-server.sh        # Docker, firewall, вход только по ключу, swap

# .env на сервере (не в git): ключи + DOMAIN и POSTGRES_PASSWORD
cd /opt/foodfinder && docker compose -f docker-compose.prod.yml up -d --build

# обновление после пуша в GitHub
sh /opt/foodfinder/deploy/deploy.sh
```

Своего домена нет — подойдёт `DOMAIN=<ip-через-дефисы>.sslip.io`, например `203-0-113-10.sslip.io`:
он указывает на IP сервера, и Caddy получит для него настоящий сертификат.
Railway — в [backend/README.md](backend/README.md#деплой-на-railway).

Для локальной разработки без почты можно включить `SMTP__DEV_LOG_CODES=true` —
код подтверждения появится в логе бэкенда.
