# Frontend

Чистые HTML, CSS и JavaScript (ES-модули), без сборки и зависимостей. Шрифты — Nunito
(заголовки) и Manrope (текст) из Google Fonts.

## Запуск

Нужен запущенный бэкенд на `http://localhost:8000`.

```bash
cd frontend
python -m http.server 5173
```

Открыть http://localhost:5173. Через `file://` не заработает: браузер не грузит ES-модули с диска.

Порт 5173 выбран не случайно — он прописан в CORS бэкенда (`APP__CORS_ORIGINS`).
Если фронт живёт на другом адресе, добавьте его туда.

## Страницы

| Файл | Что там |
|---|---|
| `index.html` | Лендинг |
| `auth.html` | Вход, регистрация, ввод кода из письма |
| `orders.html` | Мои закупки: история, новая закупка |
| `order.html?id=N` | Закупка: корзина, адрес, поиск, подборка, письма |
| `profile.html` | Профиль, тема, удаление аккаунта |

На страницах после входа справа внизу — чат с Морковкой. На странице закупки она видит эту
корзину и может её поправить по просьбе.

## Структура

```
css/
  variables.css   цвета, радиусы, тени — светлая и тёмная тема
  base.css        сброс, типографика, шапка, подвал
  components.css  кнопки, поля, карточки, бейджи, тосты, модалки
  mascot.css      анимации морковки
  pages.css       стили конкретных страниц и чата
js/
  env.js          адрес API для прода (см. ниже)
  theme.js        применяет тему до отрисовки, чтобы не мигало
  config.js       адрес API, интервал запросов
  api.js          клиент API: токен, очередь запросов, разбор ошибок
  utils.js        el() для DOM, форматирование, тосты, мини-markdown
  layout.js       шапка, подвал, проверка входа, выбор региона
  mascot.js       SVG-морковка с настроениями
  icons.js        линейные иконки
  chat.js         чат с агентом
  pages/          код каждой страницы
assets/favicon.svg
```

## Что стоит знать

- **Лимит запросов.** Бэкенд пускает 3 запроса в секунду. `api.js` сам выдерживает интервал
  между запросами и повторяет запрос после 429, так что страницы в лимит не упираются.
- **Безопасность вывода.** Всё, что пришло от пользователя или из интернета (названия поставщиков,
  ответы агента), попадает в страницу только как текст — через `el()`, без `innerHTML`.
  Ответы агента в markdown разбираются в безопасное подмножество. Ссылки — только http(s).
- **Токен** хранится в `localStorage`. Если бэкенд ответил 401 — токен стирается, пользователь
  уходит на вход и после него возвращается на ту же страницу.
- **Тема** берётся из системы, переключатель в шапке и в профиле запоминает выбор.

## Прод

Укажите адрес бэкенда в `js/env.js`:

```js
window.FF_API_BASE = "https://<ваш-бэкенд>/api/v1";
```

и добавьте адрес фронта в `APP__CORS_ORIGINS` бэкенда. Фронт — обычная статика: подойдёт nginx,
отдельный static-сервис на Railway или раздача из того же контейнера.
